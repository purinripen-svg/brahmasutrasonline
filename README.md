BrahmaSutrasOnline

«Study. Understand. Contemplate.»

BrahmaSutrasOnline is an open-source project dedicated to creating a modern, fast, and academically responsible digital edition of the Brahma Sūtras (Vedānta Sūtras).

The goal is to make the Brahma Sūtras freely accessible to students, teachers, researchers, and spiritual seekers worldwide through a clean, searchable, and mobile-friendly website.

---

Features

- Complete collection of all 555 Brahma Sūtras
- Original Sanskrit (Unicode)
- IAST transliteration
- Carefully attributed English translation
- Browse by Adhyāya and Pāda
- Fast search
- Responsive design
- Traditional commentary references
- Cross-references
- Lightweight HTML, CSS, and JavaScript
- GitHub Pages deployment

---

Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- JSON
- GitHub Pages

No frontend frameworks or build tools are required.

Editorial Principles

The project aims to:

- Preserve the Sanskrit text faithfully.
- Use consistent IAST transliteration.
- Clearly distinguish primary text, translation, commentary, and editorial notes.
- Respect copyright and provide proper attribution.
- Present major Vedānta traditions fairly.
